## About

I build tools that make software explain itself — record/replay debugging for LLM systems, verified migrations, and evidence-first data products.

**11 public projects shipped in my first year on GitHub**, across AI infrastructure, developer tooling, and iOS. I care less about making software *look* intelligent than about making its decisions traceable, testable, and reproducible.

Open to software and AI engineering roles.
